repository's `go-test-with-agent-cli-guard.sh`, and `-race`. Fake executors and
loopback HTTP only; no installed agent CLI is executed.

The larger affected sweep:

```text
go test -race -v ./internal/pipeline ./internal/handler ./internal/service ./cmd/server ./cmd/multica \
  -run 'TestPipeline|TestDocumentAssociation|TestIssueExecution|TestSelectedIssue|TestFrozenExecution|TestResolvePipeline' -count=1
```

passed five packages: 49 top-level tests and 111 subtests, no skips. Its CLI
checkpoint had 68 process cases; the final CLI checkpoint after adding the
multiline-description assertion passed **70 real subprocesses**, alongside the
long Markdown-description database test. Final compiler/plan checks passed
12 top-level tests and 31 subtests. Final targeted frozen-dispatch checks passed
with three actual queued/completed fake tasks. These are overlapping checks,
not additive unique test totals. Raw logs accompany the issue delivery.

Core `vitest run pipelines documents`: **12 files / 131 tests passed** after
compiler-2 action guards and metadata edits. Core TypeScript, downstream views
TypeScript, changed core-file ESLint and `git diff --check` passed. The views
check verifies exported type compatibility; it is not a UI interaction test.

Agent authentication rejection is proved with a minted task token over real
HTTP; a raw identity header on a handler fixture is not authentication evidence.
