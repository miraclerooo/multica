## Build and rollout boundary

Apply migrations and integrate/review the new backend before the following UI
phase. Current release numbers are not a compatibility floor; the exact
capabilities and release-channel environment/build flags are documented in
[the API/core/CLI contract](v1.5.md). Review-only binary construction can use:

```sh
# Run from server/. Fill the exact delivery commit; do not install this file
# over a running CLI or restart a production daemon as part of verification.
DELIVERY_COMMIT=<exact-delivery-commit>
go build -ldflags "-X main.version=dev-v1.5-${DELIVERY_COMMIT} -X main.commit=${DELIVERY_COMMIT} -X main.buildCommit=${DELIVERY_COMMIT} -X main.releaseChannel=ipoke" -o bin/multica-v1.5-review ./cmd/multica
bin/multica-v1.5-review version --output json
```

Production upgrade-guide configuration is intentionally not invented. A custom
channel with no configured guide returns `channel_not_configured`. Probing and
rechecking never run an updater, restart a daemon, or invoke a real agent.

of the history. YANF-9's later single-package 114-case pass does not make the
historical full suite green. A full `make test` rerun was not requested or run
for this increment. Native-device/Electron behavior, real runtime recovery and
